RaceDay API

Project Overview

RaceDay API is an ASP.NET Core Web API developed using .NET 8. It manages race events, categories, participant enrolments, and race results.

Technologies Used

C#

ASP.NET Core Web API (.NET 8)

SQL Server

Entity Framework Core

JWT Authentication

Swagger

xUnit Testing

GitHub Actions

Main Features

User registration and login

Role-based access for Participants and Organisers

Event and category management

Participant enrolments

Race result management

Automated testing 
Setup Instructions

Clone or download the repository.

Open the solution in Visual Studio.

Configure the SQL Server connection string.

Apply the required database setup.

Build and run the project.

Open Swagger to test the API endpoints.

Testing

Automated tests are used to verify controller functionality, authentication, and authorization.

Continuous Integration

GitHub Actions runs automated checks on the repository.
